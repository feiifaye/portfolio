# Faye Xi (Fei Xi)

Artist portfolio with Work, Visual design, Info and Research pages.

This is a static website. Open `index.html` locally, or serve the repository root with any static web host. No build step is required.

## Editing

- `index.html`: page text and layout
- `content.js`: Work projects
- `style.css`: visual styling
- `app.js`: navigation and galleries
- `assets/`: artwork and portrait images

All artwork and photographs remain the property of their respective rights holders.
